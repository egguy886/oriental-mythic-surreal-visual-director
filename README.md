# 东方异境视觉导演

> 把一个主题，变成有东方骨相、有叙事方向、能连续生长的电影级画面。

这是一个面向 Codex 等 AI 客户端的视觉导演 Skill。它把东方古典意象、中国传统纹样、神话超现实自然奇观和电影级绘画写实，整理成一套可以反复调用的视觉创作流程。

它不只是给出一串形容词，而是先确定画面的叙事核心，再让纹样、材质、尺度、光线和镜头共同服务于主题。适合做系列海报、封面、概念设定、短视频首尾帧、品牌主视觉，以及小红书等平台的高质感封面图。

## 它能做什么

- 把一个主题发展成完整的东方异境视觉方向
- 设计系列视觉圣经，固定角色、场景、纹样、材质与光线规则
- 输出 Midjourney 8.2 中英双语提示词
- 让传统纹样成为画面中的结构和叙事力量，而不是表面装饰
- 设计巨物与微小人物的尺度关系、自然异变和神话感
- 为视频或组图规划首帧、过程帧、尾帧和连续性锚点
- 对提示词进行 Style Lock，减少同一系列中风格漂移

## 使用方式

在支持 Skills 的客户端中调用：

```text
$oriental-mythic-surreal-visual-director
```

然后告诉它：

```text
帮我设计一幅“东方航海”主题的画作。
要求：神话超现实、电影级绘画写实、传统纹样显化，输出视觉方向和 Midjourney 8.2 中英双语提示词。
```

也可以继续补充画幅、用途、时代气质、主色、人物、地点、情绪或参考物。信息不完整时，Skill 会先收敛创作方向，再进入提示词阶段。

## 典型产出

一次完整任务通常包括：

1. 核心命题与视觉母题
2. 构图、尺度、材质、光线和色彩方向
3. 纹样如何进入建筑、服饰、海浪、云气或生物结构
4. 主视觉提示词与必要的负面约束
5. 中英双语 Midjourney 8.2 提示词
6. 系列延展和一致性建议

## 安装

将仓库目录放入客户端的 Skills 目录，并保留以下结构：

```text
oriental-mythic-surreal-visual-director/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── original-v0.3.md
```

在 Codex 中可以安装到：

```text
$CODEX_HOME/skills/oriental-mythic-surreal-visual-director
```

安装后重新载入 Skills，或直接使用上面的调用名。

## 关于出图

这个 Skill 负责视觉策划、提示词编排和系列一致性控制。在支持图像生成的客户端中，可以在完成视觉设计后继续调用图像生成工具；如果使用 Midjourney，则把生成的提示词复制到 Midjourney 执行。
